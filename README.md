# Leo Kinyera's Technical Blog & Portfolio

A personal blog and portfolio site covering MRI technology, AI, PCB design, and embedded systems.

## Getting Started

1. Install dependencies: `pip install zensical`
2. Set `site_url` in `mkdocs.yml` to your real public URL when you deploy (search uses it; the repo ships with a placeholder).
3. Serve locally: `zensical serve`
4. Open [http://localhost:8000](http://localhost:8000)

The site uses **navigation tabs** (Home / Blog) and a docs-style sidebar, similar to Material/Zensical documentation sites.
